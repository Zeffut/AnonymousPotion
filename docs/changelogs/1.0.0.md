First release.

Players under Invisibility have their username replaced with obfuscated text in death messages — unless they are the victim, in which case their name is shown in plain text.

- Every kind of death: melee, bow, trident, indirect deaths
- Hover and click stripped from the obfuscated name: no leak of the real username or UUID
- Custom weapon names obfuscated too, switchable off
- A killer who disconnects stays anonymous for 60 seconds
- Fail-closed: on error the message is dropped rather than sent through

Requires Paper 1.21.11 and Java 21. No dependencies.
