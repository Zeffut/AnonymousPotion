Adds anonymous usage telemetry, and a more accurate obfuscation report.

**Telemetry (PostHog)** — five events, identified by a persistent random installation UUID; this is pseudonymous, not absolutely anonymous. Set `telemetry: false` and fully restart the server to stop event sends. The `.install-id` file may still be read or created while disabled; `/reload` does not reconfigure the existing client.

- No usernames, player UUIDs or message contents are placed in events. `$ip: null` asks PostHog not to associate the source IP with the profile or record IP/geolocation properties; it does not hide the source IP from the service receiving the HTTP connection, and client code cannot verify the recipient's infrastructure handling.
- Death events report *how many* names were obfuscated and *which kind of death* it was — the vanilla translation key, validated against a whitelist so a rendered message can never take its place.
- An `obfuscation_failed` event surfaces plugin failures that were previously silent on the author's side.
- The full list of events and properties is in the README and in the plugin's `config.yml`.

**Fixes**

- Telemetry can no longer affect gameplay: its calls sit outside the fail-closed path, so a failure there can never drop a correctly obfuscated death message.
- Network calls now have connect and request timeouts, so a firewalled server no longer accumulates pending connections.

Requires Paper 1.21.11 and Java 21. No dependencies.
